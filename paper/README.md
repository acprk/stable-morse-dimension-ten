# Paper

`main.tex` is the manuscript (18 pages); `main.pdf` is the compiled version. Build with
`./build.sh` (pdflatex + biber, biblatex). The author block is a placeholder.

The PDF still contains 12 visible `\todo` markers. All of them are citation-level: page or
theorem numbers in Clemens, Harris–Tu, Fulton, Nori, Allday–Puppe and Hsiang, plus the fact
that Ma (2013) was read only through a secondary source. There is one open point of
substance: whether Artin–Mumford's computation of the exact torsion `ℤ/2` covers every web
satisfying Beauville's hypotheses. The paper reaches exactness through a deformation argument
instead (Sect. 4).
